קיסר — בונה הערים

בנה עיר רומית משגשגת

איך משחקים

  • כל מפה נחצית בדרך הקיסרית — הכביש הרחב בין שני השערים. משם מגיעים המתיישבים, ואליו מחברים את רחובות העיר.
  • עובדי השירותים הולכים רק בכבישים, אז כל שכונה חייבת להיות מחוברת.
  • הנח מגרשי מגורים ליד כביש. אוהלים יתפתחו לבתים ואחוזות ככל שתספק להם מים, מזון, דת ובידור.
  • חוות אפשר לבנות רק על אדמה פורייה (הכתמים הבהירים).
  • מזון עובר: חווה ← אסם ← שוק ← בתים. צריך את שלושתם.
  • מיסים נגבים רק מבתים בטווח הפורום.
  • שרשרת ייצור — מדרגה 3 ומעלה הבתים דורשים סחורות, לא רק שירותים:
    מכרה חימר ← בית יוצר ← כדים (דרגה 3)
    מטע זיתים ← בית בד ← שמן (דרגה 5)
    שדה פשתן ← בית אריגה ← בדים (דרגה 6)
    צריך גם מחסן לאגור את התוצרת, ושוק שיחלק אותה לבתים.
  • מדי כמה שנים יקרה אירוע: בצורת, מגפה, רעידת אדמה או דרישת מס מהקיסר. מרפאה מונעת מגפה, מהנדס מרכך רעידת אדמה, ואסם מלא שורד בצורת.
  • כפתור 🗺️ שכבות מראה מפות מידע: יוקרה, כיסוי כיבוי אש ואספקת מים.

שליטה

  • אצבע אחת — גרירה להזזת המפה, הקשה לבחירה.
  • שתי אצבעות — זום.
  • בכביש ובאמת מים אפשר לגרור קו שלם.
