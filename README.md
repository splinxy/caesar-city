# קיסר — בונה הערים

משחק בניית ערים רומי בסגנון Caesar 3, בנוי לנייד (iPhone/Android).
קובץ HTML יחיד, ללא תלויות וללא שלב בנייה. עובד גם אופליין (PWA).

## איך משחקים
- כל מפה נחצית ב**דרך הקיסרית** — כביש אבן רחב בין שני שערים. משם מגיעים
  המתיישבים, ואליו מחברים את רחובות העיר. אי אפשר לבנות עליה או להרוס אותה.
- **כביש** הוא הבסיס: עובדי השירותים מהלכים רק בכבישים, וטווח ההליכה מוגבל.
- **מגרשי מגורים** ליד כביש מתפתחים מאוהלים עד אחוזות פאר לפי השירותים שהם מקבלים:
  מים ← מזון ← דת ← מזרקה + בידור ← מרחצאות ← רפואה + יוקרה.
- **מזון**: חווה (על אדמה פורייה) ← אסם ← שוק ← בתים.
- **מים**: באר עובדת לבד; מזרקה דורשת מאגר על הנהר + אמת מים.
- **מיסים** נגבים רק מבתים בטווח הליכה מהפורום.
- **בתי מלאכה** (יוצר, בד, אריגה) מעסיקים את המובטלים ומוכרים תוצרת בכסף,
  אבל מורידים את יוקרת השכונה — הרחק אותם מהאחוזות.
- **משמר העיר** מונע שריפות, **מהנדס העיר** מונע קריסות.

## דירוגי עיר ואלים
ארבעה דירוגים במקום מספרים יבשים: **תרבות** (כיסוי מקדשים/בידור/חינוך),
**שגשוג** (דרגת דיור ואוצר), **שלום** (יורד מאסונות, מתאושש עם הזמן)
ו**חסד הקיסר**. חמישה אלים — קרס, נפטון, מרקוריוס, מארס וונוס — כל אחד
דורש מקדש משלו; אל זועם פוגע בתחום שלו (קרס מייבשת יבול, מרקוריוס שודד
מחסנים). **פסטיבל** עולה כסף ומרצה את כולם. המשימות המתקדמות נמדדות בדירוגים.

## שרשרת ייצור
מדרגה 3 ומעלה הבתים דורשים **סחורות**, לא רק שירותים:
מכרה חימר ← בית יוצר ← **כדים** (דרגה 3) · מטע זיתים ← בית בד ← **שמן** (דרגה 5) ·
שדה פשתן ← בית אריגה ← **בדים** (דרגה 6). צריך **מחסן** לאגור ו**שוק** לחלק.
מטעים ושדות פשתן מתחרים על אותה אדמה פורייה כמו החוות.

## אירועים
מדי כמה שנים קורה אירוע: בצורת, יבול שופע, מגפה, רעידת אדמה, שיירת סוחרים
שקונה עודפי מזון, או דרישת מס מהקיסר (לשלם או לסרב). כל אירוע ניתן לריכוך
בעיר בנויה היטב — מרפאה מונעת מגפה, מהנדס מרכך רעידת אדמה, אסם מלא שורד בצורת.

## מסע הכיבושים
שבעה שלבים, כל אחד עיר חדשה עם יעדים משלו (אוכלוסייה, אוצר, מצב רוח,
איכות דיור, מבני תרבות). בהשלמת היעדים אפשר לעבור לשלב הבא או להישאר
ולהמשיך לבנות. ההתקדמות נשמרת. לצד זה יש מצב **בנייה חופשית** בלי יעדים.

## תפריט ומשחקים שמורים
מסך פתיחה עם המשך / משחק חדש / טעינה. משחק חדש מתחיל **ממפה ריקה לגמרי** —
בוחרים שם עיר ומגרילים מפה (עם תצוגה מקדימה של הנהר והאדמה הפורייה).
3 משבצות שמירה ידניות + שמירה אוטומטית שהיא ה"המשך משחק".

## שליטה
אצבע אחת גוררת את המפה. אחרי בחירת מבנה — החזקה על המפה מציגה תצוגה מקדימה
עם תווית מעל האצבע, ושחרור בונה. כביש, אמת מים ומגרשים אפשר לגרור בקו.
שתי אצבעות = זום.
