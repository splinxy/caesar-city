# קיסר — בונה הערים

משחק בניית ערים רומי בסגנון Caesar 3, בנוי לנייד (iPhone/Android).
קובץ HTML יחיד, ללא תלויות וללא שלב בנייה. עובד גם אופליין (PWA).

## איך משחקים
- **כביש** הוא הבסיס: עובדי השירותים (שוק, מקדש, משמר) מהלכים רק בכבישים.
- **מגרשי מגורים** ליד כביש מתפתחים מאוהלים עד אחוזות פאר לפי השירותים שהם מקבלים:
  מים ← מזון ← דת ← מזרקה + בידור ← מרחצאות ← רפואה + יוקרה.
- **מזון**: חווה (על אדמה פורייה) ← אסם ← שוק ← בתים.
- **מים**: באר עובדת לבד; מזרקה דורשת מאגר על הנהר + אמת מים.
- **מיסים** נגבים רק מבתים בטווח הליכה מהפורום.
- **משמר העיר** מונע שריפות, **מהנדס העיר** מונע קריסות.
